# Security / 安全

Report suspected vulnerabilities privately to **hqysmail@gmail.com**. Include the
extension version, operating system, reproduction steps, impact, and a minimal
example with confidential content removed. Please keep exploit details private
while a fix and disclosure are coordinated.

请将疑似安全漏洞私密发送至 **hqysmail@gmail.com**，说明扩展版本、操作系统、
复现步骤、影响和已去除保密内容的最小示例。在协调修复和公开披露期间，
请不要将利用细节发布到公开 issue。

Security review targets the current public development source and latest released
extension. Older versions may require an upgrade. This project does not promise a
response deadline; support and fixes depend on maintainer availability. The email
address is the reporting channel; this document does not assert that GitHub private
vulnerability reporting is enabled.

安全审查面向当前公开开发源码和最新发布的扩展。旧版本可能需要升级。
维护者会根据可用时间处理报告，本项目不承诺响应时限。上述邮箱为举报渠道；
本文不表示 GitHub 私密漏洞报告功能已启用。
